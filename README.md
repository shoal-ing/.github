# shoal-ing/.github

The organization profile for [shoal-ing](https://github.com/shoal-ing).
`profile/README.md` is what GitHub shows on the organization page; `assets/`
holds its banner, the organization avatar and the logo.

The banner, avatar and logo are rendered in
[`shoal-ing/website`](https://github.com/shoal-ing/website) by
`tools/render-og.sh` (sources: `tools/banner-render.html`,
`tools/avatar-render.html`, `assets/favicon.svg`). Re-render there and copy
them here; do not edit the PNGs by hand. The avatar is uploaded by hand at
`github.com/organizations/shoal-ing/settings/profile`: GitHub has no API for it.
