**Shoal rehearses your launch before you post it.** Paste your launch post or README. Thousands of simulated developers
read it, upvote it, argue about it and decide whether to install. You get the predicted thread, the
top objections and the edits that change the outcome.

- **Seed.** Shoal parses your post into claims, calls to action and install steps, and sets the
  venue, the posting time and a calibrated baseline.
- **Simulate.** Ten thousand agents from 38 developer segments read, vote and reply over 48
  simulated hours. Jev, the deterministic engine, decides who acts and when; an LLM writes text
  only when an agent posts.
- **Score.** The predicted thread, sentiment over time, install intent by segment, the top trust
  flags, and the edits ranked by how much they change the outcome.
- **One binary.** Open-core, written in Rust, self-hostable. A local model or an API.
